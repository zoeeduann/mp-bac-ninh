## 1. 登录后台

**网址**: `https://www.mindfulpeaceth.com/admin`

**账号**: 由系统管理员开通,角色有两种:
- `admin` — 全部权限
- `staff` — 只管理账号绑定的学堂，包括该学堂的页面资料、活动、预约与笔记；不能改网址、站点归属、排序、账号或全局设置

例如：善明小院的 `staff` 账号绑定「越南北宁善明小院」后，登录同一个后台，只会看到并管理善明小院的页面、活动、预约与笔记，不会进入泰国总门户设置，也不能查看其他学堂的账号。

忘记密码: 找系统管理员重置。

**后台界面语言切换**: 左下角头像菜单 →「设置」→「语言」可以切中/英。注意:这只是改**后台界面**显示的语种,**跟内容语种是两回事**(内容语种在每条记录右上角切换)。

## 2. 整体结构

左侧导航的几个主要 collection:

| 名称 | 中文 | 用途 |
|------|------|------|
| `activities` | 活动 | 公开活动(禅修课、读书会、茶会等) |
| `reservations` | 预约 | 访客通过网站提交的预约 |
| `journal` | 学堂笔记 | 学堂活动现场记录、文章 |
| `locations` | 学堂 | 当前账号所属学堂的基础信息；管理员可看全部学堂 |
| `categories` | 类别 | 活动分类(读书会、茶会、禅修等) |
| `media` | 媒体 | 所有上传的图片(hero、海报、QR 等) |

## 3. 日常任务

### 3.1 新建活动 ⭐ 最常做

1. 左侧「活动」→ 右上「创建新条目」
2. **左上角语种是「中文」**(默认),**先填中文,英文可以全部留空**(AI 会自动翻)
3. 必填字段:
   - **标题** — 例如「禅茶读书会-《活着为什么》」
   - **slug** — **留空!** AI 会自动翻成英文 slug。手填要全英文小写+连字符(例如 `chan-tea-reading-club`),**绝对不要填中文**
   - **类别** — 下拉选一个
   - **学堂** — 必选(决定这活动属于哪个学堂)
   - **主图** — 拖一张图进来,**先压到 800KB 以内**(超过 4.5MB 会上传失败)
   - **简短描述** — 240 字以内
   - **名额上限** — 例如 12
4. **场次** ⭐ 重要:
   - 点「+ 添加行」加场次
   - 每条场次填**开始时间** + **结束时间**(用日期选择器,**不要只点日期、记得点时间**——常见踩坑)
   - 场次状态:`Open`(可预约)/ `Full`(已满)/ `Cancelled`(已取消)
5. **详细描述**(可选): 富文本,可以加图片、标题、列表
6. **状态**:
   - `草稿` — 写一半先存,前台看不到
   - `已发布` — 公开,会出现在活动列表
   - `已归档` — 隐藏(已结束的留存)
7. 右上「保存」 → 等 2-4 秒(后台在调 AI 翻英文)→「已保存」

**保存后**:
- 右上切到英文 locale,检查 title/shortDesc/description 是不是都填好了
- 学堂名是不是拼音(Xindeng / Ruru / Heguang)
- 如果英文还是空 → 见 [§5.2](#52-翻译偶发失败)

### 3.2 编辑/发布已有活动

1. 「活动」→ 点活动名进入编辑
2. 改任何字段 →「保存」
3. **改了中文不会自动重翻英文**。如果想让 AI 重翻,**先清空英文 locale 那个字段** → 保存,就会触发重翻

### 3.3 处理新预约

访客提交预约后,系统会**自动发邮件**到管理员邮箱 `mindfulpeacecm@gmail.com`。

后台处理:

1. 左侧「预约」→ 列表按时间倒序
2. 默认列:**入口来源 / 创建时间 / 姓名 / 活动 / 状态 / 访客留言 / 内部备注**
3. 点进一条:
   - **访客留言** = 访客自己填的"想说的话"
   - **内部备注** = **你写的**,只有 admin/staff 看得到 — 用来记录电话/微信沟通结果
4. 改 **状态**:
   - `待确认 pending` (新进)
   - `已确认 confirmed` (已联系并确认参加)
   - `候补 waitlist` (没位置时)
   - `已取消 cancelled`
   - `已删除 deleted` (软删除,不真删)
5. 「保存」— 改成「已确认」会自动记录"谁、什么时间确认的"

### 3.4 写学堂笔记 (Journal)

1. 「学堂笔记」→「创建新条目」
2. 同活动一样,左上**先填中文**:
   - **标题**
   - **slug** — 留空,AI 自动翻
   - **日期**(必填,显示在文章顶部)
   - **学堂**(选哪个学堂的笔记)
   - **封面图**(必填)
   - **正文**(富文本)
   - **照片集**(可选,多图)
3. 状态选「已发布」→ 保存
4. 切英文 locale 检查翻译

### 3.5 改学堂基础信息

1. 「学堂」→ 选择要编辑的学堂；`staff` 账号只会看到自己所属的学堂
2. 可改字段(下面是高频几项):
   - **学堂名 / 城市 / tagline**(英文别忘了切语种填)
   - **学堂故事** — 首页中间那段长文
   - **修学之意一句话** — 故事下方那行小注脚,空就用默认「静坐、喝茶、读书、行走。」
   - **地址 / Google Maps 嵌入 URL** — 从 Google Maps → 分享 → 嵌入地图 → 复制 iframe 里的 `src=` 那串
   - **微信号 / WhatsApp / 邮箱** — footer 显示用
   - **团队成员**(数组,每条:姓名+照片+简介)
   - **FAQ**(数组,每条:问+答)
3. 保存即生效(前台动态读取,**不需要等任何东西,刷新前台就能看到**)

### 3.6 替换学堂 Logo / Hero 图

直接在「学堂」编辑页 → **点 logo/hero 字段右边的 ✕** 移除旧的 → 上传新的 → 保存。
新图自动同步到云端,前台刷新就用新图,不需要做任何别的。

⚠️ 文件 **> 4.5MB 会上传失败** — 提前在本地压一下:
- Mac:在 Finder 里右键图 → 快速操作 →「转换图像」选 HEIC/JPEG 50% 质量
- 或在线压: `https://squoosh.app`(免费,不需要登录)

### 3.7 创建/编辑活动类别

1. 「类别」→ 创建新条目
2. **类别名** (zh/en): 「读书会」/「Reading Club」
3. **slug** (英文): 用作 URL 参数,例如 `reading`
4. **排序权重**: 数字越大越靠前(`tea-gathering: 6` 会排在 `meditation-class: 0` 前面)

### 3.8 上传 / 替换图片素材

1. 「媒体」→「创建新条目」→ 上传文件
2. **图片内容说明会由 AI 自动填写** — 给视障读者/搜索引擎看；需要时可直接修改，人工内容不会被覆盖
3. 学堂笔记保存后，还会结合文章标题、正文和图片说明，生成文章专用的图片说明
4. 用在哪儿:其它 collection(活动、学堂等)的图片字段里都能挑这张图
5. **活动海报自动适配**：竖版图片保存后自动生成 3:2 横版封面，重新排列主题、主要文字和画面，去掉二维码。活动卡片（含首页、越南语页和推广落地页）、详情封面与下载海报配图共用 3:2 横版构图；链接分享预览单独按 1200×630 排版。原图只作为后台生成素材，不在前台展示。在媒体编辑页面可以预览、核对文字并点击「重新生成横版封面」。已有图片可点击「生成横版封面」。生成期间或失败时仍可正常保存，前台暂不展示图片，不回退到原海报；重试失败不会替换已生成的封面。

## 4. AI 帮你做的事

### 4.1 中文 → 英文自动翻译

**什么时候自动翻**:
- 活动 / 学堂笔记状态 = 「已发布」
- 英文 locale 该字段为空
- 中文 locale 该字段有内容

**自动翻**:
- 标题
- 简短描述(自动控制在 240 字内,不会因为英文比中文长被拒)
- 详细描述(富文本,保留排版、加粗、列表等)

**保留**:
- 静心学堂 → Mindful Peace Academy
- 如如 / 心灯 / 和光 → Ruru / Xindeng / Heguang(**不会被翻成 Suchness / Heart Lamp**)
- 曼谷 / 清迈 / 普吉 → Bangkok / Chiang Mai / Phuket

**重要**:
- AI 翻译**偶尔失败**(大约 5%,网络瞬态错误)→ 表现为保存成功但英文还是空 → 见 [§5.2](#52-翻译偶发失败)
- **手填的英文永远不会被覆盖** — 如果你手填了英文,以后中文怎么改,英文都不动。想让 AI 重翻,先清空英文那个字段

### 4.2 slug 自动从中文翻译

留空 slug → AI 把中文标题翻成英文短句 → 转成网址形式(`chan-tea-reading-club` 这种)。学堂名走拼音。

### 4.3 活动海报自动生成

每个**已发布**活动详情页底部都有「下载海报」按钮:
- 点 → 新标签打开海报页 → 浏览器自动下载 PNG
- 海报里**自动带 QR 码**,扫码跳活动详情 + 自动打开预约表
- 可以发朋友圈/微信群

### 4.4 微信号点击复制

所有页面里的学堂微信号(报名弹窗、预约页、页脚)都可以**点击复制** —— 点了变「已复制 ✓」2 秒。访客不用手抄。

## 5. 常见问题 & 自救

### 5.1 保存按钮一直转圈不结束

**可能**: AI 翻译挂住了(网络偶发)

**自救**:
- 等 12 秒(系统设了硬超时)
- 如果还转,刷新页面 → 数据通常已经存了,只是英文可能还是空 → 改任意字段(加空格再删)保存触发重翻

### 5.2 翻译偶发失败

**症状**: 保存成功,但英文 locale 那个字段是空的

**自救**: 改任何一个字段(加一个空格再删就行)→ 保存。因为英文是空的,会再翻一次。多数情况第二次就成。

### 5.3 字段保存被拒「下面的字段是无效的」

**最常见**: 简短描述超 240 字 — 砍短就好。

**别的字段被拒**:
- slug 不唯一(已经有别的活动用过) — 改一个英文 slug
- 必填字段忘了填 — 看红色星号的都要填

### 5.4 上传图片失败 / 提示文件过大

文件 > 4.5MB。提前压一下再传(见 [§3.6](#36-替换学堂-logo--hero-图))。

### 5.5 列表页想加/减显示的列

后台列表页右上「**列**」按钮 → 勾选要显示的字段。**只对你这个浏览器生效**,不影响别人。

### 5.6 改了内容但前台没变

- 大部分内容(活动、笔记、学堂、媒体):前台动态读 DB,**刷新就生效,不用等**
- 等 15 秒后再刷一次还是没变,见 [§6](#6-什么情况要找技术)

### 5.7 网址打不开 / 404

- 活动/笔记的 slug 是中文 → 中文 URL 在微信/Safari 跳不动 → 后台改成英文 slug
- 检查活动「状态」是不是「已发布」(草稿在公开网址打不开)

### 5.8 想看一条预约/活动的修改历史

后台目前不显示历史(每次保存覆盖)。如果误改了想恢复,联系技术,可以从数据库备份找回。

## 6. 什么情况要找技术

**技术联系微信**: `lynnnnnnn-`(长按复制)

| 情况 | 描述 |
|------|------|
| 后台登不上 | 浏览器试无痕窗口;还不行找系统管理员重置密码 |
| 网站打不开(全站) | 隔 5 分钟再试一次;还不行找技术 |
| 改了内容前台一直不变 | 隔 1 小时再刷一次;还不行找技术 |
| 表单提交不了 / 邮件没发出 | 找技术看日志 |
| 想加新的字段 / 新的功能 / 改样式 | 找技术 |
| 误删了重要数据想找回 | **立刻**找技术(数据库有备份,但**只保留 7 天**) |
| 想看流量、收录、性能数据 | 找技术帮你导出 |

### 维护说明：启用横版封面生成

- 在网站运行环境设置 `ARK_API_KEY`（火山方舟签发）。可用 `ARK_IMAGE_MODEL` 覆盖默认的 `doubao-seedream-5-0-pro-260628`，`ARK_BASE_URL` 覆盖默认的北京区域地址。密钥只放在服务端环境变量中。
- 迁移 `20260906_140000_media_landscape_cover` 与泰国站同名同内容。两站共用同一数据库，泰国站已执行过，北宁站部署时会视为已完成；新建的本地数据库上重复执行也安全。
- 两站共用数据库，横版封面记录在同一媒体条目上：在任一站后台生成后，两站都会引用这张封面。
- 图片会提交到火山方舟的豆包 Seedream 图片编辑接口，按张计费（输入 0.02 元、输出 0.3 元，合计约 0.32 元一张）。输出直接按 1536×1024 请求，正好是 3:2，并已关闭水印。生成的文字仍需师兄核对，中文标题尤其要逐字看一遍。
- 若某张图返回「可能被内容审核拦截」，多半是画面里有可辨识的真人。换一张原图，或改用后台其它配图，不要反复重试。
- 新上传的竖图会在保存响应后自动生成；生成服务缺失或失败会在媒体页面显示状态，不阻止保存。旧图在媒体页面点「生成横版封面」即可，无需重新上传。
- 若运行平台中断后台任务，等待五分钟后可在媒体页面重试；不会自动反复调用付费接口。后台上传和生成路由需要支持 300 秒执行时长。


### 批量统一活动卡片封面

在「媒体」列表展开「批量统一活动横版封面」，点击「加载 / 刷新活动图片」，选择学堂后开始生成。此操作将所选已发布活动的原海报发送给火山方舟豆包，产生图片生成费用，并自动用于网站卡片。每批最多 3 张；已生成或人工修正的封面会跳过，原图保留。保持页面打开，可在本批完成后暂停；中断后重新加载即可继续。遇到失败会暂停，先检查原因再继续。

新封面统一为 3:2 横版，突出主题和主要文字，去掉二维码、日期、时间、地址及报名信息，活动当前信息由卡片文字区显示。完成后逐张核对主要文字和图像。单张媒体页面仍可重新生成。


### 按版位查看媒体

在媒体编辑页点击「查看版位与尺寸」，查看该素材关联的已发布活动及实际展示图：

- **活动卡片**：3:2，720×480，自动缩放，用于列表、首页活动推荐和相关活动。
- **详情封面 / 下载海报配图**：共用高清设计母版；不为同一构图重复调用 AI。
- **链接分享预览**：1200×630，完整保留横版画面，并用活动标题、小院名称和网站域名单独排版。程序排字，不额外调用图片生成服务；活动或封面更新后，分享图片地址随之更新。
- **后台缩略图**：240×240，自动生成，仅供媒体库快速识别。

「设计母版」表示重新生成的横版文件，不是群里的原海报；原海报只保留为后台素材。未关联已发布活动的媒体会说明引用范围，不误报为已使用。此面板只统计活动封面，其他栏目按其页面配置使用。

新上传不再生成闲置的 OG 裁切文件；小于高清尺寸上限的图片不再重复生成同尺寸 hero 文件。现有旧文件保留兼容，不批量删除。
