# 北宁善明小院：中文广告落地页

## 已确认的目标

用户已确认：善明小院所有活动与课程均为公益项目，免费参加。两版页面首屏、活动方向说明、费用问答和留资表单旁均明确说明公益免费。

面向北宁对佛学、静心文化、禅修感兴趣的中文用户。不同广告素材进入匹配的内容页面，先了解小院、建立信任，再留下姓名和 Zalo，由小院跟进咨询。

## 两个入口

| 入口（上线后）          | 适配素材                 | 主要行动                         |
| ----------------------- | ------------------------ | -------------------------------- |
| `/discover/mindfulness` | 正念活动、禅茶、禅意生活 | 页内填写姓名、Zalo，了解活动安排 |
| `/discover/buddhism`    | 佛学、共读、次第修学     | 页内填写姓名、Zalo，了解课程安排 |

页面均为中文，不修改原有首页、活动详情、预约流程及其他语言页面。独立布局不加载 Google Ads、GA、广告再营销或外部分析标签。

## 内容与信任

使用北宁站公开的小院实景、品牌介绍、地址与活动案例。资料从公共 CMS API 只读获取，每 60 秒可刷新；不修改 CMS 记录。案例使用明确的已有活动 slug，不把所有读书会自动归为佛学课程。

未公布的新课程、授课老师、开课日期和学员评价不编造。费用已由用户明确确认为所有活动与课程均免费。往期活动明确标注；已经开课的系列班不作为新招生班展示。活动 API 不可用时隐藏案例、保留介绍和咨询；小院资料不可用时展示重试提示，避免误绑定留资地点。

## 留资和后台

- 两项联系资料：姓名、Zalo **注册手机号**。明确提示非越南号码带国家区号，保留本地号码的前导零。
- 用户需勾选同意小院通过 Zalo 回复本次咨询。
- POST 到现有 `/api/reservations`，使用 `source=book_general_inquiry`，保存为 pending 咨询，不占活动名额。
- 复用既有必填 phone 字段：填写的 Zalo 注册手机号同时作为 phone 和 zaloId，不增加第三个输入项，也不伪造号码。
- notes 记录咨询入口、联系同意说明，以及可选的 utm_source / utm_medium / utm_campaign / utm_content。只保留长度受限的白名单字段，不保存任意 URL 参数、不保存 utm_term 或 gclid。
- 姓名与号码不会发送至分析服务。没有新建受众、自动加好友、自动发 Zalo、自动入群等功能。
- 复用既有同源校验、限流及 honeypot。若部署启用 Turnstile，则表单相应启用验证。
- 只有服务器明确返回成功和记录 ID 后才展示“已收到你的咨询”；失败保留输入，发送中防止连续点击。

## 匿名漏斗统计

网站内部按越南日期、页面方向和 UTM 广告系列/素材汇总三步漏斗：

1. **访问次数**：每次加载落地页记录一次；刷新会再次计数，所以这是访问次数，不是精确独立人数。
2. **开始填写**：访客第一次编辑姓名或 Zalo 时记录一次；联系同意勾选本身不计入。
3. **成功咨询**：仅在服务器已把咨询写入数据库后计数；验证失败、限流、网络错误和伪造的前端请求不会计入。

后台进入「广告漏斗统计」，可按日期、正念/佛学页面、utm_campaign 和 utm_content 查看访问、开始填写、成功咨询、两段流失量及转化率。统计表只保存汇总数字和长度受限的 UTM 白名单字段，不保存访客级事件、姓名、Zalo、IP、Cookie、完整 URL、gclid 或任意查询参数，也不向 Google 发送数据。漏斗写入失败不会影响真实咨询提交。

广告 URL 示例（上线后使用；不要在参数中填联系人信息）：

```text
https://mindfulpeacebacninh.com/discover/mindfulness?utm_source=google&utm_medium=cpc&utm_campaign=bacninh_launch&utm_content=creative_a
https://mindfulpeacebacninh.com/discover/buddhism?utm_source=google&utm_medium=cpc&utm_campaign=bacninh_launch&utm_content=creative_b
```
