## 1. 目标

学堂经常要为活动制作海报,发到**微信朋友圈/群、小红书、Facebook、Instagram**。本工具让运营者**选一个已有活动,即可一键生成一张做好设计、严格符合品牌 VI 的海报图片**并下载,无需设计软件。

- **全自动**:海报内容来自活动数据(标题、时间、地点、配图),不做自由编辑器。
- **对齐官方 VI**:版式严格照搬 VI 规范 A-13-1「活动海报模板」。
- **多平台**:输出竖版 4:5 与方版 1:1,中英文各一版。

### 1.1 非目标(YAGNI)

- 其它海报类型(节日问候、通知公告、金句分享)——本期只做**活动海报**。
- 二维码、报名按钮等可交互元素(静态图无意义)。
- Canva 式自由编辑器(改字号/拖拽/换布局)。
- 服务端出图接口(Satori/无头浏览器)——本期用浏览器端截图;若日后需要批量/可分享图片 URL 再评估。
- 4:5、1:1 以外的尺寸(如 9:16、公众号横版)。

## 3. 版式规格(对齐 VI A-13-1)

自上而下、自左而右:

1. **满屏照片**铺底(`socialImage` 或 `heroImage`)。
2. **菩提叶水印**(VI A-14 辅助图形):贴右侧出血,白色,约 16% 透明度。
3. **左上 logo**:白色反白「静心学堂 | 心灯/如如/和光」标准组合。
4. **右侧品牌色竖条**:占右边一窄条,内含**竖排(writing-mode 直排)活动主题**,白字。
5. **左下文案区**(白字,叠在照片+渐变压暗上):活动一句话文案。
6. **底部突出日期**:小标签「活动时间 · TIME」+ 大号粗体日期时间;下方小字「地点:…」。
7. **无二维码**。

**压暗处理**:左侧 + 底部柔和渐变 scrim,保证白字在任意照片上可读;整体保持安静氛围,不过曝、不过艳(VI A-13-1 原则)。

### 3.1 品牌色值(VI A-13)

- 标准色 虚空蓝 `#82C1EB`(R130 G193 B235)
- 辅助色 靓蓝 `#1C76A6` / 沉香 `#928178` / 茶色 `#DA9E83`
- 渐变蓝 `#82C1EB` → `#9ACFF0` → `#D3EDFB`

竖条颜色从**靓蓝/沉香/茶色**三者中按照片主色调自动选择(同色系优先,可手动覆盖)。

## 4. 架构与组件

设计目标:把「海报长什么样」收敛到**单一来源** `PosterCanvas`,工具页与出图逻辑都围绕它,互不耦合。

### 4.1 数据模型改动

- `activities` 集合新增**可选**字段 `socialImage`(upload → media)。
- 用途:为社媒图单独挑一张最佳照片;留空则回退 `heroImage`。
- 迁移:纯增量字段,Drizzle `push:true` 可直接同步(见 [[project_db_schema]] 约定:增量改动安全,删除/重命名才需先生成迁移)。

### 4.2 `PosterCanvas` 组件(设计唯一来源)

- 按**精确像素**渲染海报(1080×1350 或 1080×1080)。
- Props:
  - `content`:{ academyLockup, theme(活动主题), copy(一句话文案), dateLine, venueLine, photoUrl }
  - `size`:`'4x5' | '1x1'`
  - `locale`:`'zh-CN' | 'en'`
  - `themeFont`:`'serif' | 'calligraphy'`
  - `barColor`:品牌辅助色之一
- 职责单一:只负责按 props 渲染,不取数、不出图、不算颜色。
- 复用网站既有品牌 token / 字体。

### 4.3 工具页:Payload 后台自定义视图

- 放在 **Payload 后台**:注册一个自定义视图 `admin.components.views.<key>`(`path` 如 `/poster-studio`,`Component` 为视图组件),由 `payload generate:importmap` 自动写入 `importMap.js`(**不手改**),复用后台**鉴权**——无需自建访问控制。运营者本来就在后台管理活动,入口顺手。
- 取数走 **Payload Local API**(视图的服务端入口),非公开 REST;列出已发布活动(中英两 locale),**页内按学堂筛选**(单一共享视图,不是按路由分学堂)。
- 流程:选活动 → 实时预览 `PosterCanvas` → 选项面板(尺寸/语言/主题字体/竖条颜色) → 下载。
- 中英 × 两尺寸 = 最多 4 张,**逐张下载**。一次性打包(zip)v1 不做(避免引入 JSZip 等依赖),后续需要再加。
- `PosterCanvas` 与截图均在后台页面里**客户端**运行,不受后台框架影响。

### 4.4 出图工具

- 浏览器端把 `PosterCanvas` 节点截成 PNG(`modern-screenshot` 或 `html-to-image`),缩放到 1080px 宽。
- **关键约束**:照片须**同源**(经 Next 图片优化 `/_next/image` 或同源代理)以避免 canvas 跨域污染导致截图失败。这是全案**最高风险点**——实施计划须把「浏览器实测一张能成功导出」作为**前置门槛**(先验证截图链路打通,再做 UI/选项),而非留到最后 QA。
- 截图前 `await document.fonts.ready`,确保中文字体/书法体已加载。

### 4.5 竖条自动选色工具

- 从照片采样主色调 → 映射到最近的品牌辅助色(靓蓝/沉香/茶色)。
- **轻量实现**(不引第三方调色板库):把照片缩到极小尺寸的离屏 canvas → 取平均/量化主色 → 在感知色彩空间里取最近的品牌辅助色。
- 始终提供**手动覆盖**(三色下拉)兜底。

---

## 5. 数据流

1. 后台视图经 Payload Local API 取已发布活动(zh-CN + en),页内按学堂筛选。
2. 运营者选活动 + 选项。
3. `PosterCanvas` 按选项渲染(内容/语言/字体/颜色/照片)。
4. 竖条颜色由照片自动算出(可被手动覆盖)。
5. 点下载 → 截图节点 → 按所选尺寸/语言导出 PNG → 下载文件。

- **各学堂白色反白 logo 组合**(曼谷如如 / 清迈心灯 / 普吉和光),**优先 SVG**(便于生成白版、缩放清晰);仅 PNG 则需深/白各一张透明图。

- **新增 npm 依赖**:DOM 截图库(如 `modern-screenshot`)。

## 7. 风险与对策

| 风险 | 对策 |
|---|---|
| 跨域照片导致 canvas 污染、截图失败 | 照片走同源(Next 优化/代理);浏览器实测 |
| 截图字体渲染不准 | 截图前 `document.fonts.ready`;字体预加载 |
| 书法字体商用授权 | **演示佛系体已确认全渠道免费商用**(纪国才/Keynote研究所·秋叶PPT 首发);喜鹊燕书待核实。默认宋雅无需该字体即可上线 |
| 自动选色误判 | 始终保留手动覆盖 |

## 8. 测试

- **单元**:竖条选色映射工具(主色 → 品牌辅助色)。
- **组件**:`PosterCanvas` 结构快照(含中英、两尺寸、两字体分支)。
- **手动(关键)**:浏览器实测两尺寸 × 两语言的截图产物——图片保真度无法纯单测覆盖,须人工核验。

- 运营者在 **Payload 后台**的海报工具视图里选任一已发布活动,能预览并下载符合 VI A-13-1 的 PNG。
- 4:5 与 1:1、中文与英文均可出图,导出宽度 1080px。
- 海报含:满屏照片、菩提叶水印、白色带地方名 logo、右侧品牌色竖条+竖排主题、左下文案、底部突出日期;无二维码。
- 竖条颜色自动按照片选色且可手动覆盖;活动主题可在宋雅/书法间切换。
- `socialImage` 未填时正确回退 `heroImage`。
